# Transições: o corte também conta a história

A transição é o "como" a cena entra. Ela liga a energia da cena anterior à energia desta.

## 1. Energia → transição

| Da cena anterior para esta | Boa escolha |
|---|---|
| calma → calma | `fade`, `iris`, `cut` |
| calma → tensão | `cut` seco, `glitch`, `flash` |
| tensão → tensão | `cut`, `wipe`, `blinds` (rápido, sem respiro) |
| tensão → virada | `zoom`, `match`, `flash` (a virada merece o golpe mais forte) |
| virada → mecanismo | `push`, `slide`, `wipe` (organiza) |
| mecanismo → mecanismo | `push` ou `slide` na mesma direção (sensação de sequência) |
| mecanismo → prova | `zoom`, `iris`, `wipe` |
| qualquer → impacto | `flash`, `match`, `cut` antes de uma pausa |

## 2. Regras

- **`cut` é uma escolha, não preguiça.** Cortes secos dão ritmo; use em tensão e logo antes de um momento forte.
- **No máximo 2 transições de efeito seguidas** (`spin`, `glitch`, `flash`, `match`, `zoom`). Depois, uma simples (`cut`, `fade`, `push`).
- **Não repita a mesma transição em cenas vizinhas**, exceto `push`/`slide` numa sequência de mecanismo (aí é intencional).
- **`match`** só quando a cena anterior tem uma palavra-chave forte que se conecta com esta ("*Risco*" → cena do bloqueio).
- **`spin`** e câmera `spin_in` são irmãos: não use os dois na mesma cena.
- **`glitch`** só combina com tecnologia, segurança, erro, ataque. Em luxo, saúde e imobiliário, não.
- **A primeira cena** entra depois do logo: prefira `fade`, `wipe` ou `iris`.
- A cena de herói que continua da anterior (mesmo herói) usa `cut` ou `fade`: o objeto já está na tela.

## 3. Som

O sistema põe os efeitos sonoros sozinho: whoosh em `wipe`, `push`, `slide`, `spin`, `blinds`; impacto em `flash`, `zoom`, `match`, `glitch`. Escolha a transição pensando também no som que ela vai ter.
