# Variação: cada versão é um filme diferente

Toda versão do vídeo tem uma **semente** (seed). Ela sorteia duas coisas que você recebe no briefing:

1. **ÂNGULO CRIATIVO**: como contar a história (pergunta, antes e depois, um dia na vida, contagem regressiva...).
2. **RECEITA VISUAL**: a personalidade do movimento do filme (Editorial calmo, Kinetic bold, Tech glitch, Revista/colagem, Cinemático, Pop jovem, Suíço minimal, Luxo respirado...). Ela lista os efeitos preferidos.

## Como usar

- **Siga o ângulo de verdade.** Se o ângulo é "abra com uma pergunta", a primeira headline é uma pergunta. Não é decoração.
- **A receita é o sotaque, não uma prisão.** Use os efeitos preferidos da receita na maioria das cenas e quebre o padrão em uma ou duas, quando a frase pedir.
- **Contexto vence a receita.** Se a receita sugere glitch e a marca é de saúde, não use glitch. O sistema já tira o que não combina, mas confira.
- **O mesmo pitch com outra semente = outra escolha.** Mude a ordem das batidas, a cena de impacto, o herói em destaque, o tipo de prova.

## Anti-repetição

- Cenas vizinhas não repetem efeito de texto, câmera nem transição.
- Barra/bloco atrás do texto (`bar`, `block`): no máximo 1 a cada 3 cenas.
- Elemento girando: no máximo em metade das cenas.
- Se duas ideias parecem iguais, uma delas não é uma ideia.
